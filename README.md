你是一个资深Python开发工程师，请严格按照以下完整需求实现**定时获取指定城市天气的小程序**，全程遵循规范、健壮、可配置、可维护原则。

# 任务描述
开发一个**纯本地运行、无GUI、无服务端、无数据库**的Python天气小程序，支持**定时自动获取**指定城市的实时天气数据，支持配置管理、日志记录、数据校验、工具函数封装，代码结构清晰、可直接运行。

# 功能需求
1. **天气获取**：通过免费天气API获取指定城市的实时天气（温度、湿度、天气状况、风向、更新时间）。
2. **定时任务**：支持按分钟/小时定时自动刷新天气，无需人工重复执行。
3. **配置管理**：城市名称、定时间隔、API密钥统一从配置文件读取。
4. **数据校验**：对API返回数据、城市名称、配置参数进行合法性校验。
5. **日志记录**：程序运行、请求成功/失败、定时触发、错误异常全部写入日志文件。
6. **结果输出**：天气数据格式化输出到控制台，并保存到本地文本文件。
7. **异常处理**：网络异常、API失败、配置错误、数据缺失均捕获并友好提示。

# 强约束条件
1. **文件夹路径约束**
   - 配置文件必须存放于 `./config/` 目录，文件名固定为 `settings.yaml`
   - 日志文件必须存放于 `./logs/` 目录，按日期自动生成
   - 天气结果文件必须输出到 `./output/` 目录
   - 所有路径必须使用**相对路径**，禁止使用绝对路径
2. **特定文件格式约束**
   - 配置文件必须使用 `.yaml` 格式，不允许使用json/ini
   - 天气输出文件必须使用 `.txt` 格式
   - 日志文件必须使用 `.log` 格式
3. **命名规范约束**
   - 所有Python文件名使用**snake_case**（小写+下划线）
   - 所有类名使用**PascalCase**（大驼峰）
   - 所有函数、变量使用**snake_case**
4. **不可修改约束**
   - 程序运行时不得修改/删除 `./config/settings.yaml`，仅允许读取
   - 不得覆盖历史日志文件，按天滚动存储

# 文件结构要求（必须包含以下6个文件）
1. `main.py` —— 程序入口，启动定时任务
2. `config.py` —— 配置加载器，读取yaml配置
3. `weather_fetcher.py` —— 天气API请求核心模块
4. `validator.py` —— 数据与配置校验模块
5. `logger_setup.py` —— 日志初始化模块
6. `utils.py` —— 通用工具函数（时间格式化、文件保存等）
